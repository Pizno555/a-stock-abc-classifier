## 1. 评级范围与事实基础

评分前先定义“评级范围/投资命题”。主题股票池默认评价公司在该主题下的真实暴露、商业化和利润兑现；整体公司评价则覆盖主要利润来源和可验证的增量利润来源。二者不得混用。若两者结论不同，并列输出，例如“整体公司A；AI芯片主题受益B”。

评分前整理事实底稿。每项关键输入至少记录命题、来源、日期、支持或反对方向、冲突、缺口和置信度，并区分已确认事实、分析推断和未知。外部材料已有证据标记时保留原标记，不在本框架内重新分级。

事实使用规则：

- A类关键结论需要独立事实相互印证；同一原始材料被多家转载只算一项输入。
- 关键数据超过一个财报周期未更新时降低置信度。
- 公司自述可以证明“公司说过”，不能单独证明客户采用、市场份额或未来订单。
- 缺失数据记为未知；未知越多，置信度越低。

### 事实充分性与闸门状态

每道闸门必须且只能选择以下状态之一；不得使用“通过/部分通过”等斜杠并列标签：

| 状态 | 定义 | 评级影响 |
|---|---|---|
| 通过 | 正面事实达到该闸门要求，且关键结论有足够事实支持 | 不设额外上限 |
| 部分通过 | 已有真实业务或兑现，但规模、持续性、分部口径或独立验证仍有关键缺口 | 公司最高B |
| 失败 | 已有反面事实明确证明未达到要求，或触发真实性/持续经营否决 | G1/G2失败通常归C；重大G3失败归C或放弃 |
| 未知 | 现有材料无法确认通过或失败 | 不得评A；给暂定等级、区间或暂不评级 |
| 尚未进入验证 | 上游业务尚未产生可评价的订单、收入或财务结果 | 不把它写成财务失败；由G1/G2状态决定等级 |
| 不适用 | 该闸门对已明确适配的商业模式确实不成立 | 说明替代检验；不得为填表强行评分 |

材料缺失不是反面事实。“未通过A类硬门槛”不等于“闸门失败”。

## 2. 三道公司闸门

### G1 真实暴露

检查目标业务在收入、毛利、增量利润和资本投入中的地位。

- **通过**：已形成有意义的收入/利润贡献，或是主要增长来源。
- **部分通过**：已产生收入但占比较低，或利润贡献不清。
- **失败**：仅有研发、送样、合作意向、参股、规划或在建产能。

G1失败通常归C；部分通过最高为B。

### G2 商业化

验证“产品—认证—订单—产能—交付—收入”。

- **通过**：稳定量产并有连续交付或复购证据。
- **部分通过**：认证、小批量、产能爬坡或单一订单。
- **失败**：只有产品发布、样品、实验室指标、框架协议或传闻。

至少一名可独立验证的客户已发生多张独立订单、明确复购或跨采购周期的连续验收时，可以判G2通过；同一张订单的分批交付或分批验收仍只算一次，通常为部分通过。其他经销收入的终端穿透不足应进入D3、D4或G3的证据缺口，不得把已验证的商业化事实改写成斜杠状态。

G2部分通过最高为B；失败通常归C。

### G3 财务兑现

检查营收、扣非利润、毛利率、现金流、应收、存货、合同负债、资本开支和减值。

- **通过**：主营增长与现金和营运资金大体匹配，至少两个连续报告期可验证。
- **部分通过**：利润出现但现金或营运资金暂时背离，且有可核验解释。
- **失败**：持续依赖非经常损益，或利润增长伴随无法解释的应收、存货和现金流恶化。

G3部分通过最高为B；重大真实性或持续经营疑点归C或放弃。

补充规则：

- G1/G2已经失败且目标业务尚无收入、利润或营运资金时，G3记为“尚未进入验证”，不是“失败”。
- “尚未进入验证”要求现有证据正面确认目标业务尚无订单、收入或财务结果；若目标业务被合并披露、现有材料无法确认其有无收入或订单，G3应记为“未知”，不能用阶段标签替代缺失证据。
- 目标业务已有有意义收入，但分部利润、现金或营运资金无法拆分；若整体公司连续至少两个报告期的利润、现金和营运资金大体匹配，G3记为“部分通过”，不得据此评A。
- 只有已出现利润或收入后，存在持续非经常损益依赖、无法解释的现金/应收/存货恶化、审计受限或真实性疑点时，才写G3失败或重大失败。

## 3. 公司质量100分模型

公司质量分完全排除当前股价、估值、市场预期和交易拥挤度。每个维度按0—5给原始分，再按权重折算：

`维度得分 = 原始分 / 5 × 维度权重`

维度得分可保留一位小数，总分不先取整，避免边界误判。产品价格、行业ASP和成本周期属于公司基本面证据，可以进入D1/D4/D6；股票价格、股票估值和持仓拥挤不得进入公司质量分。

### 缺失数据与评分区间

- 不把未知维度记为0分或默认中性分，也不按剩余维度重新归一化到100。
- 维度证据只支持一个范围时，给维度上下限；完全不可评分时，该维度区间为`0—该维度权重`并明确这只是数学边界。
- 只有D2、D3、D4均可评分、至少5个维度可评分、已覆盖权重至少80%时，才输出公司质量单点分。
- 不满足单点评分条件时，合计各维度上下限，输出公司质量区间；覆盖权重低于60%时原则上暂不输出总分。
- 置信度高要求覆盖权重至少90%、关键维度完整且关键来源独立；置信度中要求覆盖权重至少80%；其余为低。
- A类要求单点分或区间下界达到80、全部硬门槛通过且置信度至少中；未知或部分通过的关键闸门不得评A。
- 仅当完整证据形成的单点分低于60，或合理区间上界仍低于60时，才能仅凭总分判C。
- 已有真实小批供货且G1/G2部分通过、未触发C类否决时，优先归B或暂定B；不得因未知维度被低分化而自动归C。
- B类质量区间可以因未知维度而跨过60分线；此时必须说明B来自“真实业务已存在但尚未闭环”的闸门状态，区间下界只是缺失数据压力测试，不代表已形成C类反证。

### D1 产业需求与方向：10分

检查终端需求、价值量、渗透率、价格/销量、库存、资本开支和政策依赖。

- 0—1：需求主要来自叙事或短期事件。
- 2：产业存在但需求弱、周期向下或政策依赖强。
- 3：方向成立，节奏或持续性不明。
- 4：需求由多项数据验证且处于扩张期。
- 5：需求强、持续时间长，供需和终端数据相互印证。

### D2 真实业务暴露：10分

优先看增量利润贡献，其次看毛利和收入占比。参股收益、代理贸易和未并表资产单列。

- 0—1：仅概念、规划或间接关联。
- 2：已有小额收入，利润贡献不清。
- 3：业务重要但非主要驱动。
- 4：主要增长和利润来源。
- 5：高度纯正，利润弹性直接映射产业需求。

### D3 商业化、客户与订单：20分

检查产品阶段、认证、客户质量、订单类型、复购、客户集中度、交付周期和收入可见度。

- 0—1：产品或意向阶段。
- 2：送样/认证或小额试单。
- 3：批量供货，但客户、份额或持续性不清楚。
- 4：多期稳定交付，客户和订单质量较高。
- 5：规模出货、复购和份额领先，未来数季可见度高。

不得把框架协议全额当订单，不得把产能规划当销售预测。

### D4 财务兑现与质量：20分

至少检查：

- 主营收入与扣非利润增速；
- 毛利率、净利率及单位盈利；
- `近四季度经营现金流 / 近四季度归母净利润`；
- 应收账款增速减营收增速；
- 存货增速减营收增速；
- 周转、减值、资本化、补助、汇兑和投资收益。

- 0—1：没有兑现或质量明显异常。
- 2：收入增长但利润/现金弱。
- 3：初步兑现，有一项重要缺口。
- 4：收入、利润和现金大体匹配。
- 5：连续兑现，质量和单位经济性优于同行。

### D5 竞争壁垒与龙头性：20分

检查技术、良率、成本、认证、产能、供应链、渠道、生态、品牌、份额、研发转化和议价能力。

- 0—1：同质化、缺乏准入或依赖单一关系。
- 2：具备能力但无领先证据。
- 3：局部优势，份额或盈利一般。
- 4：主要指标领先，多重壁垒成立。
- 5：持续扩大份额，领先优势难以复制。

### D6 持续性与产业周期：15分

检查产品迭代、价格下降、竞争扩产、行业库存、客户资本开支、替代路线和未来6—18个月可见度。这里判断产业和盈利周期，不使用股票价格。

- 0—1：盈利接近周期顶部、产品被替代或增长不可持续。
- 2：增长可能但持续性弱。
- 3：至少未来两个季度可见，远期不明。
- 4：未来一年驱动清晰且供给受控。
- 5：多产品、多客户或多周期驱动，持续性强。

### D7 治理与资产负债表：5分

检查大股东行为、关联交易、商誉、担保、诉讼、监管问询、融资依赖、偿债和会计政策。

- 0—1：重大治理或财务风险。
- 2：风险偏高或披露不足。
- 3：基本正常。
- 4—5：治理稳健、资产负债表有韧性、披露透明。

## 4. 公司ABC判定规则

按以下优先级判定，不得只看总分：

1. 先执行否决规则：G1或G2失败、重大G3失败或重大治理/持续经营风险，归C或放弃；
2. 再检查A类全部硬门槛；只有总分、维度下限、三道闸门、结论置信度同时满足才可评A；
3. 未触发C类否决、但未满足A类全部条件的真实业务，归B；
4. 总分低于60时归C，不用其他维度高分补偿。

这里的“总分低于60”只适用于满足单点评分条件的完整评分，或评分区间上界低于60；不得对数据覆盖不足的伪精确单点分执行该规则。

G3“部分通过”或可解释的阶段性现金错配，最高为B；若持续依赖非经常损益，或应收、存货、现金流恶化无法解释，则属于重大G3失败并归C或放弃。

### A类

同时满足：

- 公司质量分 ≥ 80；
- D2 ≥ 7/10、D3 ≥ 14/20、D4 ≥ 14/20、D5 ≥ 14/20、D6 ≥ 9/15；
- G1、G2、G3全部通过；
- 置信度至少为中；
- 无重大否决项。

股价、估值和拥挤度无论多高，都不直接降低公司A等级。

### B类

满足任一：

- `60 ≤ 公司质量分 < 80`；
- 总分达到80，但任一A类硬门槛未满足；
- G1/G2/G3仅部分通过；
- 产业或业务真实，但商业化、盈利质量、竞争格局或持续性有明显缺口。

### C类

满足任一：

- 公司质量分 < 60；
- G1或G2失败；
- 明确事实证明目标业务仍停留在规划、送样或概念阶段；仅因分部披露缺失而“现有材料无法验证”不属于本项，须按未知处理；
- 增长主要依赖非经常性收益、题材或不可持续交易；
- 出现重大财务真实性、治理或持续经营风险。

股价下跌和低估值不能覆盖C类硬伤。

## 5. 价格与市场状态100分模型

此分数与公司ABC分开。分数越高，当前价格和交易结构越有吸引力。

### M1 估值安全边际：50分

建立悲观、基准、乐观情景，判断当前市值隐含哪一种情景。选择适合商业模式的方法：

- 稳定盈利：PE、PEG、FCF收益率、ROIC；
- 重资产/周期：PB、EV/EBITDA、单位产能价值和中周期利润；
- 早期成长：EV/S、EV/毛利并结合明确盈利路径；
- 多业务：分部估值，避免各业务都使用最乐观可比估值。

评分锚点：

- 0—1：只有极端乐观情景才能支撑；
- 2：明显透支，安全边际低；
- 3：大体合理；
- 4：基准情景有吸引力；
- 5：悲观情景仍有较好保护。

折算公式：`M1 = 原始分 / 5 × 50`。采用周期股中周期利润或多业务分部估值时，明确关键假设，避免用景气顶点利润制造虚假低估。

M1最低输入：估值基准日与市值/企业价值、匹配商业模式的盈利或资产口径、悲观/基准/乐观情景，以及历史区间或同行可比中的至少一项交叉验证。缺任一核心输入时，不给M1单点分；只给区间或定性判断。

常见不合格组合：只给PE、同行倍数和历史分位，即使三者都显示便宜，只要缺少悲观/基准/乐观三情景价值，M1仍未满足最低输入，价格总分未知且不得称“好资产”。

### M2 预期饱和度：30分

比较股价变化、FY1/FY2盈利预测修正、市场隐含增长、预测分歧和催化剂是否已被充分交易。

- 0—1：市场已按极端乐观结果定价；
- 2：预期高度饱和；
- 3：预期大体匹配基本面；
- 4：仍有合理预期差；
- 5：市场预期明显低于可验证基本面。

折算公式：`M2 = 原始分 / 5 × 30`。盈利预测只是辅助证据，必须回到订单和财务验证。

M2最低输入：同一窗口的股价变化、FY1/FY2盈利预测修正，以及市场隐含增长、预测分歧或催化剂计价中的至少一项。只有“股价上涨但单一预测未变”时，可以判断预期趋满，但不得给M2精确单点分。

### M3 拥挤与退出状态：20分

按 [crowding-analysis.md](crowding-analysis.md) 计算0—100拥挤风险分，并反向映射：

`M3 = 20 × (100 - 拥挤风险分) / 100`

拥挤数据不足时标记未知；需要总分时给区间，不假设中性。

价格与市场状态只有在M1、M2、M3均可单点评分时才给单点总分。任一项只能给区间或定性状态时，总结也必须使用区间或定性状态；不得把低置信度单点子分拼成精确总分，也不得据此判“好资产”。

### 市场状态分层

| 分数 | 状态 |
|---:|---|
| `75 ≤ 分数 ≤ 100` | 好价格/好交易结构候选 |
| `60 ≤ 分数 < 75` | 价格合理 |
| `40 ≤ 分数 < 60` | 预期较满或价格偏贵 |
| `0 ≤ 分数 < 40` | 价格差或交易结构脆弱 |

## 6. 好公司与好资产矩阵

| 公司等级 | 价格与市场状态 | 资产结论 | 默认研究动作 |
|---|---|---|---|
| A | `75 ≤ 分数 ≤ 100`且拥挤风险≤75 | 好资产 | 核心候选，结合风险分批配置 |
| A | `60 ≤ 分数 < 75` | 好公司＋合理价格 | 观察或分批，不把一般价格写成便宜 |
| A | `40 ≤ 分数 < 60` | 好公司但价格一般/偏贵 | 等待回调或新的业绩上修 |
| A | `0 ≤ 分数 < 40` | 好公司但价格差 | 不追高，等待估值和拥挤改善 |
| B | 任意 | 待验证公司 | 价格低也不能替代商业和财务验证 |
| C | 任意 | 非核心公司 | 低价不升级，原则上不作核心仓 |

“好资产”必须同时满足公司A、价格状态≥75、拥挤风险≤75，且公司与价格关键数据置信度至少为中。拥挤风险>75时，即使估值安全边际很高，也不得称“好价格/好交易结构”或“好资产”：若综合分≥75，写成“A公司＋估值可能有吸引力，但交易结构极度拥挤”；若综合分<75，保留对应的“合理/一般/差”价格结论并追加“极度拥挤”。若估值或拥挤数据缺失，不得直接下好资产结论。若用户只要求公司ABC，资产结论写“当前价格未评估”，不要为填满模板而补猜市场分。

## 7. 反证与升降级

### 公司ABC触发器

- **升级**：认证转量产、试单转复购、利润占比提升、单位盈利改善、现金匹配、份额提升。
- **降级**：客户流失、产品延期、毛利持续恶化、应收/存货异常、扩产闲置、份额下降。
- **放弃**：订单或客户真实性被否定、重大会计问题、核心路线被替代、持续经营或治理风险显著。

### 价格状态触发器

- **改善**：股价回调但盈利预测和订单不变、业绩上修快于股价、拥挤和杠杆下降。
- **恶化**：股价上涨快于盈利兑现、乐观情景被完全定价、拥挤和融资继续上升。

价格状态变化不得写成公司ABC升降级。

## 8. 同行比较规则

- 统一观察时点、财报期间、币种和会计口径。
- 公司ABC比较相同产品层级和商业模式；价格比较使用匹配的估值方法。
- 区分增速来自低基数、并购、涨价、放量还是份额提升。
- 不重复奖励同一驱动；新品放量已体现在收入和毛利时，壁垒只评价难复制程度。
- 股票池观察时点、报告期、产品定义或会计口径不一致时，不输出排名、梯队、行序暗示或跨公司分数区间比较。保持用户输入顺序或按证券代码排列，只给各自时点事实卡和统一补证清单。
