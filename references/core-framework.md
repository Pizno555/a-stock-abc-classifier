## 1. 证据等级

评分前先定义“评级范围/投资命题”。主题股票池默认评价公司在该主题下的真实暴露、商业化和利润兑现；整体公司评价则覆盖主要利润来源和可验证的增量利润来源。二者不得混用。若两者结论不同，并列输出，例如“整体公司A；AI芯片主题受益B”。

| 等级 | 典型来源 | 用法 |
|---|---|---|
| S | 财报、公告、交易所/监管文件、正式合同 | 核心事实依据 |
| A | 投资者关系记录、客户/交易对手资料、可独立验证的数据 | 与S级交叉验证 |
| B | 产业数据库、招投标、价格/库存/开工数据、行业协会资料 | 验证景气和链条 |
| C | 券商研报、专家纪要、财经媒体 | 建立假设和寻找线索 |
| D | 论坛、社交媒体、群聊和未署名消息 | 仅作线索，不计分 |

规则：

- A类关键结论至少有两项独立S/A证据；同一公告被多家转载只算一项。
- 关键数据超过一个财报周期未更新时降低置信度。
- 公司自述可以证明“公司说过”，不能单独证明客户采用、市场份额或未来订单。
- 缺失数据记为未知；未知越多，置信度越低。

## 2. 三道公司闸门

### G1 真实暴露

检查目标业务在收入、毛利、增量利润和资本投入中的地位。

- **通过**：已形成有意义的收入/利润贡献，或是主要增长来源。
- **部分通过**：已产生收入但占比较低，或利润贡献不清。
- **失败**：仅有研发、送样、合作意向、参股、规划或在建产能。

G1失败通常归C；部分通过最高为B。

### G2 商业化

验证“产品—认证—订单—产能—交付—收入”。

- **通过**：稳定量产并有连续交付或复购证据。
- **部分通过**：认证、小批量、产能爬坡或单一订单。
- **失败**：只有产品发布、样品、实验室指标、框架协议或传闻。

G2部分通过最高为B；失败通常归C。

### G3 财务兑现

检查营收、扣非利润、毛利率、现金流、应收、存货、合同负债、资本开支和减值。

- **通过**：主营增长与现金和营运资金大体匹配，至少两个连续报告期可验证。
- **部分通过**：利润出现但现金或营运资金暂时背离，且有可核验解释。
- **失败**：持续依赖非经常损益，或利润增长伴随无法解释的应收、存货和现金流恶化。

G3部分通过最高为B；重大真实性或持续经营疑点归C或放弃。

## 3. 公司质量100分模型

公司质量分完全排除当前股价、估值、市场预期和交易拥挤度。每个维度按0—5给原始分，再按权重折算：

`维度得分 = 原始分 / 5 × 维度权重`

维度得分可保留一位小数，总分不先取整，避免边界误判。产品价格、行业ASP和成本周期属于公司基本面证据，可以进入D1/D4/D6；股票价格、股票估值和持仓拥挤不得进入公司质量分。

### D1 产业需求与方向：10分

检查终端需求、价值量、渗透率、价格/销量、库存、资本开支和政策依赖。

- 0—1：需求主要来自叙事或短期事件。
- 2：产业存在但需求弱、周期向下或政策依赖强。
- 3：方向成立，节奏或持续性不明。
- 4：需求由多项数据验证且处于扩张期。
- 5：需求强、持续时间长，供需和终端数据相互印证。

### D2 真实业务暴露：10分

优先看增量利润贡献，其次看毛利和收入占比。参股收益、代理贸易和未并表资产单列。

- 0—1：仅概念、规划或间接关联。
- 2：已有小额收入，利润贡献不清。
- 3：业务重要但非主要驱动。
- 4：主要增长和利润来源。
- 5：高度纯正，利润弹性直接映射产业需求。

### D3 商业化、客户与订单：20分

检查产品阶段、认证、客户质量、订单类型、复购、客户集中度、交付周期和收入可见度。

- 0—1：产品或意向阶段。
- 2：送样/认证或小额试单。
- 3：批量供货，但客户、份额或持续性不清楚。
- 4：多期稳定交付，客户和订单质量较高。
- 5：规模出货、复购和份额领先，未来数季可见度高。

不得把框架协议全额当订单，不得把产能规划当销售预测。

### D4 财务兑现与质量：20分

至少检查：

- 主营收入与扣非利润增速；
- 毛利率、净利率及单位盈利；
- `近四季度经营现金流 / 近四季度归母净利润`；
- 应收账款增速减营收增速；
- 存货增速减营收增速；
- 周转、减值、资本化、补助、汇兑和投资收益。

- 0—1：没有兑现或质量明显异常。
- 2：收入增长但利润/现金弱。
- 3：初步兑现，有一项重要缺口。
- 4：收入、利润和现金大体匹配。
- 5：连续兑现，质量和单位经济性优于同行。

### D5 竞争壁垒与龙头性：20分

检查技术、良率、成本、认证、产能、供应链、渠道、生态、品牌、份额、研发转化和议价能力。

- 0—1：同质化、缺乏准入或依赖单一关系。
- 2：具备能力但无领先证据。
- 3：局部优势，份额或盈利一般。
- 4：主要指标领先，多重壁垒成立。
- 5：持续扩大份额，领先优势难以复制。

### D6 持续性与产业周期：15分

检查产品迭代、价格下降、竞争扩产、行业库存、客户资本开支、替代路线和未来6—18个月可见度。这里判断产业和盈利周期，不使用股票价格。

- 0—1：盈利接近周期顶部、产品被替代或增长不可持续。
- 2：增长可能但持续性弱。
- 3：至少未来两个季度可见，远期不明。
- 4：未来一年驱动清晰且供给受控。
- 5：多产品、多客户或多周期驱动，持续性强。

### D7 治理与资产负债表：5分

检查大股东行为、关联交易、商誉、担保、诉讼、监管问询、融资依赖、偿债和会计政策。

- 0—1：重大治理或财务风险。
- 2：风险偏高或披露不足。
- 3：基本正常。
- 4—5：治理稳健、资产负债表有韧性、披露透明。

## 4. 公司ABC判定规则

按以下优先级判定，不得只看总分：

1. 先执行否决规则：G1或G2失败、重大G3失败或重大治理/持续经营风险，归C或放弃；
2. 再检查A类全部硬门槛；只有总分、维度下限、三道闸门、证据置信度同时满足才可评A；
3. 未触发C类否决、但未满足A类全部条件的真实业务，归B；
4. 总分低于60时归C，不用其他维度高分补偿。

G3“部分通过”或可解释的阶段性现金错配，最高为B；若持续依赖非经常损益，或应收、存货、现金流恶化无法解释，则属于重大G3失败并归C或放弃。

### A类

同时满足：

- 公司质量分 ≥ 80；
- D2 ≥ 7/10、D3 ≥ 14/20、D4 ≥ 14/20、D5 ≥ 14/20、D6 ≥ 9/15；
- G1、G2、G3全部通过；
- 置信度至少为中；
- 无重大否决项。

股价、估值和拥挤度无论多高，都不直接降低公司A等级。

### B类

满足任一：

- `60 ≤ 公司质量分 < 80`；
- 总分达到80，但任一A类硬门槛未满足；
- G1/G2/G3仅部分通过；
- 产业或业务真实，但商业化、盈利质量、竞争格局或持续性有明显缺口。

### C类

满足任一：

- 公司质量分 < 60；
- G1或G2失败；
- 目标业务停留在规划、送样、概念或不可验证阶段；
- 增长主要依赖非经常性收益、题材或不可持续交易；
- 出现重大财务真实性、治理或持续经营风险。

股价下跌和低估值不能覆盖C类硬伤。

## 5. 价格与市场状态100分模型

此分数与公司ABC分开。分数越高，当前价格和交易结构越有吸引力。

### M1 估值安全边际：50分

建立悲观、基准、乐观情景，判断当前市值隐含哪一种情景。选择适合商业模式的方法：

- 稳定盈利：PE、PEG、FCF收益率、ROIC；
- 重资产/周期：PB、EV/EBITDA、单位产能价值和中周期利润；
- 早期成长：EV/S、EV/毛利并结合明确盈利路径；
- 多业务：分部估值，避免各业务都使用最乐观可比估值。

评分锚点：

- 0—1：只有极端乐观情景才能支撑；
- 2：明显透支，安全边际低；
- 3：大体合理；
- 4：基准情景有吸引力；
- 5：悲观情景仍有较好保护。

折算公式：`M1 = 原始分 / 5 × 50`。采用周期股中周期利润或多业务分部估值时，明确关键假设，避免用景气顶点利润制造虚假低估。

### M2 预期饱和度：30分

比较股价变化、FY1/FY2盈利预测修正、市场隐含增长、预测分歧和催化剂是否已被充分交易。

- 0—1：市场已按极端乐观结果定价；
- 2：预期高度饱和；
- 3：预期大体匹配基本面；
- 4：仍有合理预期差；
- 5：市场预期明显低于可验证基本面。

折算公式：`M2 = 原始分 / 5 × 30`。盈利预测只是辅助证据，必须回到订单和财务验证。

### M3 拥挤与退出状态：20分

按 [crowding-analysis.md](crowding-analysis.md) 计算0—100拥挤风险分，并反向映射：

`M3 = 20 × (100 - 拥挤风险分) / 100`

拥挤数据不足时标记未知；需要总分时给区间，不假设中性。

### 市场状态分层

| 分数 | 状态 |
|---:|---|
| `75 ≤ 分数 ≤ 100` | 好价格/好交易结构候选 |
| `60 ≤ 分数 < 75` | 价格合理 |
| `40 ≤ 分数 < 60` | 预期较满或价格偏贵 |
| `0 ≤ 分数 < 40` | 价格差或交易结构脆弱 |

## 6. 好公司与好资产矩阵

| 公司等级 | 价格与市场状态 | 资产结论 | 默认研究动作 |
|---|---|---|---|
| A | `75 ≤ 分数 ≤ 100`且拥挤风险≤75 | 好资产 | 核心候选，结合风险分批配置 |
| A | `60 ≤ 分数 < 75` | 好公司＋合理价格 | 观察或分批，不把一般价格写成便宜 |
| A | `40 ≤ 分数 < 60` | 好公司但价格一般/偏贵 | 等待回调或新的业绩上修 |
| A | `0 ≤ 分数 < 40` | 好公司但价格差 | 不追高，等待估值和拥挤改善 |
| B | 任意 | 待验证公司 | 价格低也不能替代商业和财务验证 |
| C | 任意 | 非核心公司 | 低价不升级，原则上不作核心仓 |

“好资产”必须同时满足公司A、价格状态≥75、拥挤风险≤75，且公司与价格关键数据置信度至少为中。拥挤风险>75时，即使估值安全边际很高，也不得称“好价格/好交易结构”或“好资产”：若综合分≥75，写成“A公司＋估值可能有吸引力，但交易结构极度拥挤”；若综合分<75，保留对应的“合理/一般/差”价格结论并追加“极度拥挤”。若估值或拥挤数据缺失，不得直接下好资产结论。若用户只要求公司ABC，资产结论写“当前价格未评估”，不要为填满模板而补猜市场分。

## 7. 反证与升降级

### 公司ABC触发器

- **升级**：认证转量产、试单转复购、利润占比提升、单位盈利改善、现金匹配、份额提升。
- **降级**：客户流失、产品延期、毛利持续恶化、应收/存货异常、扩产闲置、份额下降。
- **放弃**：订单或客户真实性被否定、重大会计问题、核心路线被替代、持续经营或治理风险显著。

### 价格状态触发器

- **改善**：股价回调但盈利预测和订单不变、业绩上修快于股价、拥挤和杠杆下降。
- **恶化**：股价上涨快于盈利兑现、乐观情景被完全定价、拥挤和融资继续上升。

价格状态变化不得写成公司ABC升降级。

## 8. 同行比较规则

- 统一观察时点、财报期间、币种和会计口径。
- 公司ABC比较相同产品层级和商业模式；价格比较使用匹配的估值方法。
- 区分增速来自低基数、并购、涨价、放量还是份额提升。
- 不重复奖励同一驱动；新品放量已体现在收入和毛利时，壁垒只评价难复制程度。
